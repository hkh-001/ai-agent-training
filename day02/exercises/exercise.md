# Day 2 当日小型实践：有限历史的昵称助手

## 任务目标

用 30～60 分钟实现一个命令行助手。它能在当前消息历史中记住用户昵称，
但只保留最近 3 个用户轮次。旧昵称被裁剪后，助手应明确说“不知道”，从而
证明所谓会话记忆来自重复发送的消息，而不是 Mock Model 内部自动保存。

## 输入

- 普通文本，例如 `我叫小林`、`我叫什么？`；
- `/history`：显示当前消息历史；
- `/reset`：清空对话，仅保留 System Message；
- `/quit`：退出。

## 输出

- Mock Model 的确定性回答；
- `/history` 输出带角色的消息列表；
- 输入为空时给出错误提示，不新增消息。

## 实现步骤

1. 使用 `Conversation` 创建最大 3 轮的会话。
2. 使用 `MockChatModel`，不要调用真实 API。
3. 普通输入先追加 `user` 消息，再让模型读取完整历史。
4. 得到回答后追加 `assistant` 消息。
5. 实现 `/history`、`/reset` 和 `/quit`。
6. 依次测试昵称仍在历史和昵称已被裁剪的情况。

## 手动验收场景

```text
我叫小林
我叫什么？
```

此时应该记得“小林”。重新开始后依次输入：

```text
我叫小林
第一条
第二条
我叫什么？
```

由于最多保留最近 3 个用户轮次，昵称所在轮次已被裁剪，回答应说明当前历史中没有名字。

## 可选扩展

- 在每次裁剪时显示删除了多少条消息；
- 将最大轮次数改成启动参数；
- 比较“按消息条数裁剪”和“按完整轮次裁剪”的差别；
- 为长历史增加摘要，但不要假装摘要等于完整原文。
