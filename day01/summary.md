# Day 1 学习总结

## 今天真正建立的能力

你已经拥有两条最小运行路径：

1. `examples/mock_model.py`：无网络、无 Key、可重复测试；
2. `examples/basic_llm_call.py`：通过 OpenAI Responses API 完成真实调用。

它们使用相似的“输入→响应文本”形态，为后续替换模型和编写测试奠定基础。

## 四句话复盘

- LLM 根据上下文对后续 Token 建模并逐步生成结果。
- Token 不等于字符或单词，上下文窗口也不等于长期记忆。
- SDK 是 API 的 Python 封装，真实调用仍依赖网络、鉴权、模型权限和额度。
- 一次 LLM 调用没有行动反馈循环，因此还不是 Agent。
